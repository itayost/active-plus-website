## Gender wording rule

`gendered(fem, masc)` returns feminine only when `gender == "female"`; male and unknown get masculine (IOS/Funnel/GenderedStrings.swift:19-22). Before the gender step only welcome2 and the gender screen render, and neither is gendered. Below, "f / m" means feminine / masculine.

## Routing (FunnelOrchestrator.swift:22-96)

Linear except: chairRise -> standingComfort if `chair_rise_capability == "with_handles"`, else challengeArea; both -> reinforcement2. bodyAreas -> planBuilding always. register -> otp (web has no Apple sign-in). After OTP: new user -> merge -> payment; existing user (profile `full_name` non-empty) -> `fill_missing_funnel_answers` -> exits. Entering gender clears back-history.

## Server contract

`merge_funnel_session(p_session_id text, p_answers jsonb)` (MIG/20260613120000_signup_funnel_v5.sql:34-193): requires `auth.uid()`; GRANT to `authenticated`. Derives `functionality_level`: chair alone/with_support -> fully_independent; with_handles + seated -> chair_only; with_handles + other/null -> balance_issues; chair null -> NULL. Upserts `users` (full_name, phone/email from auth.users, date_of_birth, gender, role trainee) and `trainee_profiles` (sets is_digital=true, onboarding_completed=true), maps frequency almost_daily 6 / three_week 3 / one_two_week 2 / none 0, links `funnel_events.user_id` for the session. Returns `{success, user_id, linked_events}`. Does NOT write `daily_activity_level` or `aspiration_goal`. Does NOT clear off-branch answers (the client must).

`fill_missing_funnel_answers(p_answers jsonb)` (MIG/20260925120000_funnel_answers_existing_user.sql:262-455): existing users only; fills empty fields; never touches full_name, is_digital/is_frontal, onboarding_completed or a set level. Returns `{success, filled}`. Raises if no trainee_profiles row.

## Register + OTP

Name: f "איך תרצי שנקרא לך?" / m "איך תרצה שנקרא לך?", placeholder "הקלידו את שמכם", CTA "הבא", min 2 chars after trim, error "השם חייב להכיל לפחות 2 תווים".
Phone: "נשלח לך קוד" / "להמשך מהיר ובטוח", label "מספר טלפון", placeholder f "הקלידי מספר טלפון" / m "הקלידו מספר טלפון", "הפרטים שלך מאובטחים", CTA "שלחו לי קוד", "לוקח פחות מדקה • ללא התחייבות", consent f "בלחיצה על "שלחו לי קוד" אני מאשרת את תנאי השימוש ו מדיניות הפרטיות" / m "...אני מאשר את...", error "מספר טלפון לא תקין". Accept mobile `^05\d{8}$` only on web (the app's landline acceptance is a bug for SMS). Send E.164 `+972` + number without the leading 0.
Auth: `supabase.auth.signInWithOtp({ phone })`, `supabase.auth.verifyOtp({ phone, token, type: "sms" })`. SMS delivered by the `sendAuthOtpSms` auth hook (no web changes). OTP is 6 digits; confirm the production OTP length in the Supabase dashboard.
OTP screen: "קוד אימות נשלח אליך" / "הכנס את הקוד שקיבלת ב־SMS" / "ל-{05X-XXXXXXX}". 6 boxes, auto-verify at 6, `autocomplete="one-time-code"`. Resend after 12s: "שלח שוב בעוד {n} שניות", then "לא קיבלת קוד? שלח שוב". "ערוך מספר" returns to the phone sub-step (web: keep the number pre-filled). Overlay "מסיימים את ההרשמה..."; merge failure: "לא הצלחנו לסיים את ההרשמה" + "נסו שוב".

## Do not copy from iOS

- Paywall gender bug (session reset before paywall reads gender): web keeps gender until the payment page renders.
- Stale off-branch answers: web deletes `standing_stability` when chair != with_handles and `mobility_challenge` when chair == with_handles.
- Apple Sign-In, StoreKit product ids, hardcoded app prices (59.90/399.90), the fake 60-minute countdown, local notification scheduling.
- Back from time replaying the 9.4s loader: web's back from time goes to bodyAreas.
- `funnel_events` DDL/RLS is not in migrations: verify on the live DB before writing web events, and send `client_platform: "web"`.
